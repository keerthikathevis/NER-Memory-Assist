==================================================
A. SMART MEDICINE REMINDER SYSTEM
==================================================

Create a complete caregiver-configured medicine reminder system.

CAREgiver can create a medicine schedule containing:

- Medicine name
- Medicine photo
- Dosage/instruction text entered by caregiver
- Time
- Frequency
- Start date
- End date
- Optional voice instruction
- Active/inactive status

IMPORTANT SAFETY:
The application must NOT identify an unknown medicine from an image.
The application must NOT recommend, change or calculate medication dosage.
The application only displays information entered by the caregiver/authorized healthcare professional.

PATIENT MEDICINE SCREEN:

Show one medicine at a time in a very simple elderly-friendly layout:

- Large medicine photo
- Large medicine name
- Scheduled time
- Caregiver-provided instruction
- Taken button
- Remind Me Later button

Use clear positive confirmation after Taken.

MEDICINE HISTORY:

Record:
- scheduled
- taken
- delayed
- missed

Show date and time for each event.

CAREGIVER DASHBOARD:

Show:
- Today's medicines
- Taken
- Pending
- Missed
- Recent adherence history

If a medicine reminder is repeatedly missed, create a caregiver alert/status item.

Do not present this as an emergency medical alert.

G. MUSIC COGNITIVE ENGAGEMENT
==================================================

Create a simple working activity called:

“Listen & Match”

Flow:

1. Play a short demo audio clip.
2. Show 3 large visual choices.
3. Patient chooses the matching category/image.
4. Record:
   - correct/incorrect
   - attempts
   - response time
   - score
5. Show positive feedback.
6. Save result locally.
7. Connect the result to the existing adaptive-engine service.

Do not describe the result as a medical diagnosis.
