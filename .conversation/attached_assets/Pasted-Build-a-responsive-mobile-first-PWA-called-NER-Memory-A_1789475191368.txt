Build a responsive mobile-first PWA called “NER Memory Assist” for the Smart India Hackathon 2026 problem statement:

“AI-Based Cognitive Gaming and Memory Assistance Platform for Elderly Dementia Patients in North Eastern Region (NER).”

IMPORTANT:
This is a supportive cognitive-engagement and memory-assistance application. It must NOT claim to diagnose dementia or provide medical diagnosis.

TECHNOLOGY:
- React + TypeScript
- Vite
- Modern responsive PWA
- Clean component-based architecture
- Local/offline-first storage
- No paid APIs required for the initial prototype
- Make the application actually runnable, not just a visual mockup.

CREATE THESE USER MODES:
1. Elderly/Patient
2. Caregiver
3. Healthcare Worker

CREATE THESE INITIAL SCREENS:
1. Welcome / language selection
2. Patient Home
3. Caregiver Dashboard
4. Healthcare Worker Dashboard
5. Games
6. Medicine Reminders
7. Music & Emotional Engagement
8. Family Memories
9. Progress / Cognitive Performance
10. Settings

LANGUAGES:
The complete user interface must be designed for:
- English
- Tamil
- Hindi
- Assamese
- Bengali
- Bodo
- Meitei/Manipuri
- Khasi
- Mizo
- Nepali

Create a proper translation/i18n architecture so that selecting a language changes ALL user-facing interface text, including buttons, menus, instructions, reminders, settings and game instructions.

VOICE ASSISTANT:
Create a reusable global microphone/voice-assistant component.
It should support the selected language where the browser/device speech APIs provide it, with graceful fallback when a language is unavailable.

Voice commands should include:
- Go Home
- Open Games
- Open Medicine
- Open Memories
- Open Music
- Show Progress
- Help
- Repeat
- Start
- Pause
- Stop
- Continue
- Easier
- Harder
- Change Language

The microphone must also be available during games.

ELDERLY-FRIENDLY DESIGN:
- Very large buttons
- Large readable text
- High contrast
- Simple navigation
- Minimal text per screen
- Clear icons
- Touch-friendly controls
- Voice guidance
- Avoid clutter
- Calm, accessible design

PATIENT HOME:
Show large cards for:
- Play Games
- My Family Memories
- Medicine
- Music
- Today's Activities
- My Progress
- Voice Assistant

GAMES:
Create working placeholder game architecture with:
- Personalized Jigsaw
- Family Match-It
- NER Cultural Jigsaw
- NER Cultural Match-It

Include difficulty levels and a game-result data structure containing:
accuracy, completion time, attempts, hints used, difficulty and score.

ADAPTIVE ENGINE:
Create a reusable adaptive-engine service.
It should adjust difficulty using observed game performance:
- good performance → increase difficulty
- repeated difficulty → decrease difficulty
- use accuracy, attempts, hints and completion time
Do not use the engine for medical diagnosis.

FAMILY MEMORIES:
Create caregiver-managed memory profiles.
Each profile contains:
- photo
- name
- relationship
- voice note
- optional description

Maximum 25 active personal memory profiles.
Show usage such as “Personal Memories: 0/25”.

MEDICINE:
Create caregiver-configured medicine reminders containing:
- medicine name
- medicine photo
- schedule
- time
- frequency
- start/end date
- instructions

Patient view should show:
- medicine photo
- large medicine name
- scheduled time
- Taken
- Remind Me Later

Use local storage for the prototype so reminders/data can work offline where supported.

MUSIC:
Create a simple elderly-friendly music player interface with:
- Play
- Pause
- Next
- Previous
- Repeat
- Volume
- Voice control

Use placeholder/demo audio references only. Do not include copyrighted commercial music.

CULTURAL NER CONTENT:
Create a built-in cultural content structure for realistic NER-themed images/content such as:
- Kamakhya Temple

- Mawlynnong
- regional nature
- traditional objects

CAREGIVER DASHBOARD:
Show:
- patient activity today
- games completed
- recent scores
- performance trend
- medicine status
- missed/pending reminders
- family memory profile count
- offline/sync status

HEALTHCARE WORKER DASHBOARD:
Show non-diagnostic longitudinal performance information:
- activity frequency
- game accuracy trends
- completion trends
- difficulty progression
- adherence/activity summaries

PRIVACY:
Keep personal photos, voice notes and patient information local by default.
Do not send personal data to external AI services in this initial prototype.

OFFLINE-FIRST:
Create a storage/service architecture that can later sync with a backend.
Include an offline status indicator and a sync-status data model.

PWA:
Create:
- manifest
- service-worker-ready architecture
- installable mobile experience
- offline application shell

IMPORTANT:
First build the application foundation, routing, language system, elderly-friendly UI, patient home, caregiver dashboard, game architecture and local data models.
Do not spend time implementing a real backend yet.
Make sure the project builds and runs successfully.
